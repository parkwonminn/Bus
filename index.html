골목에 걸린 정류장은 큰 길 쪽으로 옮기도록 알려 드립니다.

설정이 필요합니다

  1. 카카오 개발자 콘솔에서 애플리케이션을 만들고 REST API 키와 JavaScript 키를 받습니다.
  2. 카카오모빌리티 길찾기 API 사용 신청을 하고 승인을 받습니다.
  3. proxy/ 를 띄웁니다. 로컬은 node proxy/server.mjs, 배포는 Cloudflare Workers.
  4. config.js 의 PROXY_URL 과 KAKAO_JS_KEY 를 채웁니다.

자세한 절차는 저장소의 README.md 를 보세요.

자주 묻는 질문

원생 주소가 어디로 전송되나요?

주소와 좌표는 본인이 운영하는 프록시를 거쳐 카카오모빌리티·카카오 로컬 API로만 전달됩니다. 국내 사업자이며, 앞선 버전에서 쓰던 해외 공개 서버로는 더 이상 나가지 않습니다. 다만 아동 개인정보를 다루는 만큼 보호자 동의와 내부 관리 절차는 별도로 갖추셔야 합니다.

REST 키가 노출되지 않나요?

REST 키는 프록시 서버에만 두고 브라우저로 내려보내지 않습니다. 정적 페이지에 들어가는 JavaScript 키는 공개를 전제로 한 키이며, 카카오 콘솔에서 도메인을 등록해 다른 사이트에서 쓰지 못하게 막습니다.

‘골목’은 무엇을 기준으로 판단하나요?

도로명 접미사를 씁니다. 한국 도로명은 ~대로, ~로, ~길 순으로 폭이 좁아지고 ~번길은 대부분 이면도로입니다. 이름을 알 수 없는 도로는 주행속도가 20km/h 미만일 때만 골목으로 셉니다.

골목을 100% 없앨 수는 없나요?

없습니다. 간선도로가 없는 주택가는 어떤 경로로도 이면도로를 지나야 합니다. 이 도구는 골목 주행을 줄이고 남은 구간을 눈에 보이게 하는 데까지만 합니다. 실제 도로 폭과 회전 반경 판단은 기사님 몫입니다.

호출 한도가 있나요?

카카오모빌리티 길찾기 API는 일일 호출 한도가 있습니다. 한 번 계산할 때 지점 수만큼 행렬 호출이 발생하므로, 지점이 많으면 한도를 빠르게 씁니다. 저장된 노선을 재사용하시면 호출을 아낄 수 있습니다.
